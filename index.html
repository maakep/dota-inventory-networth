How to use

  • Start typing anywhere, then press Enter to add the highlighted item.
  • Click an inventory to make it the target for new items.
  • Tab cycles inventories; Shift + Tab cycles backwards.
  • Alt + 1–9 selects an inventory; if it does not exist, one new inventory is created.
  • Alt + C clears the selected inventory; Alt + D removes it.
  • Drag items to swap slots. Backpack slots are the smaller grey row.
  • Aghanim’s Blessing, Aghanim’s Shard, and Moon Shard use the three consumed-upgrade slots.
  • Use the hover × or right-click to remove an item.
  • Delete removes the most recently added item from the selected inventory.
Select: Tab or Alt + 1–9
